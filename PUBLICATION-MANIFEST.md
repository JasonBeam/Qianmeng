# Public source snapshot manifest

This repository candidate contains the current application source and selected contributor documentation. It does not contain a compiled installer.

Included: application and model-core source, Windows checks source, installer/build scripts, maintenance tools, and the third-party notices required by the included gltfpack tool and .NET runtime distribution.

Excluded: the private GLB/FBX files, local default model, user-provided textures, raw conversation/tool logs, private screenshots, generated reports, test captures, local logs, backups, build outputs, and local machine paths.

The chat record is represented only by `docs/DEVELOPMENT-LOG.md`, a short technical summary. It does not reproduce the conversation.

The current working source has not been rebuilt as part of this publication preparation. The motion candidate described in the log is diagnostic-only and not accepted. Do not treat this snapshot as a verified installer or a complete animation release.
