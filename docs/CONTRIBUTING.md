# 贡献指南

欢迎提交缺陷报告、可复现步骤、设计讨论和修复。

## 环境

- Windows x64。
- .NET 10 SDK；构建 NSIS 安装器时需要 NSIS 3。
- 运行和测试时请使用自己有权使用的模型，并将模型、纹理、录屏和本机用户数据留在仓库之外。

## 提交前

- 描述 Windows 版本、运行方式和可复现步骤；区分 WPF 测试宿主、直接运行的 EXE 与 NSIS 安装版证据。
- 动作改动需提供正常速度的完整动作及返回待机视频，并检查正面、侧面和手部近景。静帧或单一数值不足以证明自然度。
- 不要提高或删除性能阈值来让失败变绿；提交前说明 CPU、内存和测试时长口径。
- 不要提交私有 GLB/FBX、纹理、桌面截图、聊天原文、用户目录、密钥、日志、备份文件或生成的验收产物。
- 新的第三方素材或代码必须先核对许可证并保留所需署名；仅写“参考”不等于获得再分发权。

## 识别系统隐私边界

后续架构草案不授权截屏、OCR、读取文档内容或向网络传送前台应用信息。新增识别适配器应说明采集数据、运行位置和用户授权方式。
