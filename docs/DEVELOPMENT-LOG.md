# 工程记录摘要

这是从项目工作记录整理的脱敏技术摘要，不是原始聊天记录。它只保留公开项目所需的实现方向、结论和未完成项。

## 已记录的方向

- Windows 是后续开发、构建和验收平台；应用使用 WPF/.NET，安装包面向 Windows x64。
- 角色模型作为用户本地素材处理，原始模型、纹理和私有测试截图不随源代码分发。
- 骨骼动作由运行时采样与全链 IK 共同生成。桌面显示尺寸与模型几何、蒙皮、材质保持分离。
- 人形动画研究关注锁骨/肩/肘/腕协同、接触时序、惯性化过渡和手指可读性；研究链接不代表复制或集成了第三方代码/动作数据。

## 已知失败与诊断

- 先前挠头候选在独立静帧审查中仍被读作手贴在耳侧，手指刮擦和接触过程不清晰，因此没有采纳。
- 30 fps WPF 测试宿主对部分挠头接近/退出时刻的记录显示，笛卡尔手腕目标混合会缩短肩腕距离并伴随较大的肘部相邻帧步进。这只是测试宿主中的几何诊断，不是对人体自然度的证明。
- 为测试“肩腕半径线性变化、方向沿最短弧变化”的单变量候选，源码加入了一个默认关闭的测试开关。此候选尚未构建、播放、独立复核或采纳。
- 项目历史中存在多份失败与旧版验收记录；它们没有被包装成当前动作通过证据。

## 后续验证要求

先对脸部、手臂和手型、触碰/解除接触及整套动作进行修复。通过正常速度完整视频、多视角近景、GPT-6.1-sol 独立复查、实际 EXE、CPU/内存和本轮 NSIS 安装生命周期检查后，才进入通用识别系统实现。验证宿主和已发布安装版应分别报告。
