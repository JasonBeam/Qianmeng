# 项目状态

本文件描述发布候选源代码的状态，不替代安装版验收。

## 已有实现

当前源代码包含 Windows 桌面伙伴界面、本地 GLB 导入与骨骼动画播放、桌面交互、活动/成长功能，以及基于本机前台应用信息的分类功能。发行版本号记录为 0.5.13。

## 尚未验收

- 人脸在待机和动作中的外观仍需与原模型同角度对照；尚无完整的材质、法线和蒙皮验收结论。
- 手臂、手指、遮挡与触碰仍需修复和以正常速度复核。
- 挠头、托腮、拥抱、叉腰等动作的接近、接触、解除接触和回待机过程尚未整套通过。
- 最新独立检查对先前候选给出未通过结论；新的测试专用腕路径候选尚未构建。
- 现有 WPF 验证宿主证据不能替代实际安装版 EXE、NSIS 生命周期、CPU 和内存验收。
- 通用识别系统仍是后续设计工作，动作验收通过前不作为已交付功能宣传。

## 本地模型

源代码仓库不分发角色 GLB、FBX 或原始纹理。运行时允许用户导入本地模型；模型的授权、蒙皮质量和可再分发权利应由使用者分别确认。

## 平台与安装器

当前目标为 Windows x64。Windows 10、ARM64 与可信代码签名尚无本机通过证据。公开源代码不代表安装包安全警告已消除。
